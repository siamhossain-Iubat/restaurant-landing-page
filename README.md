# 🍽️ Delicious Restaurant Landing Page

A modern and responsive restaurant landing page built using HTML5 and CSS3.

## 🚀 Features

- Responsive Navigation Bar
- Hero Section
- About Restaurant Section
- Popular Food Menu
- Why Choose Us Section
- Food Gallery
- Customer Testimonials
- Contact Section
- Responsive Footer
- Mobile Hamburger Menu
- Hover Animations
- Responsive Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
- Git & GitHub

## 📱 Responsive Design

The website is designed to work on:

- 💻 Desktop
- 📱 Mobile
- 📲 Tablet
